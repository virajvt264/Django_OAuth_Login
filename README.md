# 🌐 Django OAuth Authentication System

A Django-based authentication system that enables users to securely log in using OAuth providers such as **Google** and **GitHub**. Built using `django-allauth`, this project is perfect for developers who want to integrate modern authentication mechanisms into their Django applications.

---

## 🚀 Features

- 🔐 OAuth login (Google)
- 🧩 Seamless `django-allauth` integration
- 🔄 Automatic redirects after login/logout
- 🔒 Secure user session handling
- ⚙️ Easily configurable for multiple providers
- 🧱 Modular and extendable project structure
